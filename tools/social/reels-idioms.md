# Reels: Persian idioms with a cat

15 Reel ideas for the PersianMeow Instagram page, written by Shabnaz. Each Reel shows one Persian
idiom with a cat, timed to an EDM track: a hook in the first 2 seconds, then the situation, then the
punchline on the drop.

**How to use:** send prompt 0 to the video chat first, then one idea per message.

- The cat should be **Pishi** (the app's mascot) so the page and the app look like one brand.
- End every video with the same line, for example «اصطلاح بعدی رو تو کامنت بگو 😼».
- This folder is not part of the site build.

**Open points:**
- **No. 3 and 5** are crude. For Instagram, write the words with an asterisk on screen (ن*ی‌رینه).
- **No. 10:** the meaning of «میگی میره فرحزاد» isn't settled yet. Write the meaning you use, and the video chat makes the rest.

---

**۰. پرامپت کلی (اول همینو بفرست)**
```
یه سری ریلز ۱۰ تا ۱۵ ثانیه‌ای برای پیج «پرژن میو» می‌خوام. شخصیت اصلی یه گربه‌ی ایرانیه که اصطلاحات فارسی رو بازی می‌کنه. سبک: آهنگ EDM پرانرژی، کات‌های سریع روی بیت، چند ثانیه build-up و بعد پانچ‌لاین دقیقاً روی دراپ. ساختار: هوک در ۲ ثانیه اول با متن درشت روی صفحه، بعد موقعیت، بعد پانچ. عمودی 9:16، زیرنویس فارسی درشت و خوانا. تو هر پیام یه اصطلاح برات می‌فرستم.
```

**۱. گربه رو دم حجله کشتن**
```
اصطلاح: «گربه رو دم حجله کشتن» یعنی از همون اول قاطعانه قانون گذاشتن.
ویدیو: گربه‌ی رئیس روز اول با عینک دودی میاد خونه. گربه‌ی جدید دست به کاسه‌ی غذاش می‌زنه. بیت می‌خوابه... یه نگاه... دراپ! گربه‌ی جدید تا آخر عمر صاف می‌شینه.
هوک: «روز اول ازدواج، گربه‌ی من:»
کپشن: قانون از روز اول 😼
```

**۲. دستش به گوشت نمی‌رسه، میگه پیف پیف بو میده**
```
اصطلاح: گربه دستش به گوشت نمی‌رسه، میگه پیف‌پیف بو میده. یعنی چیزی که بهش نمی‌رسه رو بد جلوه میده.
ویدیو: گربه هی می‌پره تا گوشت روی کابینت رو برداره و نمی‌رسه. آخرش با حالت اشرافی روشو برمی‌گردونه و دماغشو می‌گیره. دراپ روی «پیف پیف».
هوک: «وقتی کراشت بهت محل نمیده:»
```

**۳. گوز رو به شقیقه ربط میده**
```
اصطلاح: گوز رو به شقیقه ربط میده. یعنی دو چیز بی‌ربط رو به هم ربط میده.
ویدیو: گربه‌ی کارآگاه جلوی تخته‌ی نخ قرمز وایساده. عکس کاسه‌ی خالی، جاروبرقی، همسایه و قیمت دلار رو به هم وصل می‌کنه. دراپ: «پس کار جاروبرقیه!»
هوک: «عمه‌م وقتی داره تحلیل سیاسی می‌کنه:»
```

**۴. عجب آدم شامورتی‌ایه**
```
اصطلاح: شامورتی یعنی آدم ناقلا و حقه‌باز.
ویدیو: صاحبش برمی‌گرده و ظرف شکسته‌ست. گربه با چشم‌های گنده و مظلوم نگاه می‌کنه. اسلوموشن ریوایند نشون میده خودش هلش داده. دراپ و یه چشمک.
هوک: «قیافه‌ی معصوم، پرونده‌ی سنگین»
```

**۵. نمی‌رینه که نخوره**
```
اصطلاح: کنایه از آدم خیلی خسیس (لحنش بی‌پرده‌ست).
ویدیو: گربه دونه‌دونه غذا رو می‌شمره و قایم می‌کنه. یکی دیگه میاد بو کنه و گربه گاوصندوق رو می‌بنده. دراپ: گربه روی کیسه‌ی غذا خوابیده.
هوک: «اون رفیقمون که دنگ نمیده:»
```
(برای اینستاگرام شاید بهتره تو متن روی صفحه بنویسی «ن*ی‌رینه که نخوره».)

**۶. فلانی چشم نداره منو ببینه**
```
ویدیو: گربه با یه پاپیون خوشگل وارد میشه. گربه‌ی دیگه روشو برمی‌گردونه و پشتشو می‌کنه بهش. زوم دراماتیک روی صورت حسودش و دراپ.
هوک: «وقتی تیپ می‌زنی میای مهمونی:»
```

**۷. وای چشم می‌خوری، نگو!**
```
ویدیو: یکی میگه «چه گربه‌ی سالمی، هیچ‌وقت مریض نمیشه!». همون لحظه گربه عطسه می‌کنه و از مبل میفته. دراپ و بعدش اسفند دود کردن با افکت.
هوک: «هیچ‌وقت نگو "ماشالله هیچ‌وقت..."»
کپشن: اسفند یادتون نره 🧿
```

**۸. این نیز بگذرد**
```
ویدیو: صحنه‌های بدبختی گربه پشت سر هم: حموم، دامپزشک، سشوار، رژیم. گربه با نگاه فیلسوفانه به پنجره‌ی بارونی خیره‌ست. دراپ: آفتاب، ماهی و آزادی.
هوک: «شنبه‌ها:»
```

**۹. از ما گذشت**
```
ویدیو: گربه‌ی پیر با عینک و پتو داره بچه‌گربه‌ها رو نگاه می‌کنه که دنبال لیزر می‌دوئن. یه آه می‌کشه. لیزر از جلوش رد میشه و دراپ! پیرمرد از همه سریع‌تر می‌دوئه.
هوک: «دهه‌شصتی‌ها وقتی میگن پیر شدیم:»
```

**۱۰. میگی میره فرحزاد**
```
ویدیو: گربه پنجشنبه‌شب با کلاه و ساک دستی یواشکی از خونه می‌زنه بیرون. مونتاژ سریع روی بیت: قلیون، دیزی، بلال و جوجه. دراپ: برمی‌گرده و بوی ذغال میده و یکی می‌پرسه «کجا بودی؟».
هوک: «پنجشنبه‌شب‌ها ملت:»
```
(دقیق نمی‌دونم این اصطلاح رو به چه معنی‌ای می‌گید. اگه معنیش چیز دیگه‌ایه، فقط همونو بنویس و بقیه‌ش رو چت ویدیو بسازه.)

**۱۱. موش و گربه بازی**
```
ویدیو: موش و گربه دنبال هم می‌کنن. وسط تعقیب، دراپ! وایمیسن و با هم سلفی می‌گیرن.
هوک: «من و مامانم سر قلیون:»
```

**۱۲. مثل گربه‌ی مرتضی‌علی، همیشه با چهار دست و پا میاد پایین**
```
ویدیو: گربه از هر جا میفته (مبل، کابینت، یخچال) و با اسلوموشن، صاف و فرود قهرمانی میاد پایین. دراپ: آخرین بار با عینک دودی فرود میاد.
هوک: «من وقتی هر بار تو زندگی زمین می‌خورم:»
```

**۱۳. کک تو تنبونش افتاده**
```
اصطلاح: یعنی بی‌قرار و ناآرومه.
ویدیو: گربه ساعت ۳ صبح بی‌دلیل زومیز می‌گیره و از در و دیوار بالا میره. دراپ دقیقاً وقتی که از روی صاحب خوابیده رد میشه.
هوک: «ساعت ۳ بامداد، خونه‌ی ما:»
```

**۱۴. دمشو گذاشت رو کولش و رفت**
```
اصطلاح: یعنی شکست‌خورده و دست‌خالی، بی‌صدا رفتن.
ویدیو: گربه با غرور میاد ماهی رو بدزده و صاحبش مچشو می‌گیره. یه لحظه سکوت... دراپ! گربه دمشو جمع می‌کنه، سرشو میندازه پایین و یواشکی می‌زنه بیرون.
هوک: «وقتی میری درخواست افزایش حقوق بدی:»
```

**۱۵. هندونه زیر بغلش گذاشتن**
```
اصطلاح: یعنی کسی رو الکی تعریف کردن و پرباد کردن.
ویدیو: همه دارن از گربه تعریف می‌کنن: «تو پادشاهی!». گربه هی بزرگ‌تر میشه، تاج می‌ذاره و آخرش یه هندونه‌ی واقعی زیر بغلشه. دراپ: هندونه میفته.
هوک: «وقتی بهت میگن فقط تو از پسش برمیای:»
```

یه نکته: آخر هر ویدیو یه جمله‌ی ثابت بذار، مثلاً «اصطلاح بعدی رو تو کامنت بگو 😼». این باعث میشه ملت کامنت بذارن و پیج ایده‌ی بعدی رو هم از خود مخاطب‌ها بگیره.
